
# BlogBook 
# A blog website
Visit : https://blogbook-v1-1.onrender.com/

This is a Blog website, where user can visit to read blogs and create their own blogs. This is real and totally secure with encrytions and Oauth authentication. This Website is made using MERN stack technology with several helpful libraries and tools.



## Features

- **User Authentication**: Users can register, login, and manage their accounts.
- **Blog Management**: Users can create, edit, and delete their blogs.
- **Analytics**: Basic statistics like total users, total blogs, and more.
- **Admin Panel**: Admin can manage users and blogs.

## Getting Started

### Prerequisites

To run the project locally, you’ll need:

- [Node.js](https://nodejs.org/) 
- [npm](https://www.npmjs.com/) (Node Package Manager)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/blogbook.git
   cd blogbook
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Create a `.env` file** (you may need to provide your own keys for services like Auth0):
   - Copy `.env.example` to `.env` and set the appropriate values.
   
4. **Run the project locally**:
   ```bash
   npm start
   ```

   Visit `http://localhost:3000` (not using vite), `http://localhost:5173` ( using react + vite )  in your browser to see the app in action.

### Running Tests

To run the tests (if you have any set up), use:

```bash
npm test
```
